# 🎯 Deriv Application Hub

> 🚀 **Built during GDG DevFest — Vibe Coding Lounge**  
> 📌 **Disclaimer:** This is a frontend design concept built to showcase a zero-ghosting recruitment experience. All stages and recruiter data are simulated.

🔗 **Live Demo:** [https://btrsyiarom.github.io/deriv-application-hub/](https://btrsyiarom.github.io/deriv-application-hub/)

---

### 📌 Purpose
Built in 20 minutes for the **GDG DevFest Vibe Coding Lounge** challenge: *"Keep Job Candidates Informed"*. 

It explores how a simple, Domino's-style tracking UI can eliminate candidate anxiety after applying for a job, replacing recruitment silence with complete transparency.

---

### ✨ Prototype Highlights (1-Page UI)
- **Live Stage Stepper:** Visual tracking from *Application Received* → *Resume Screen* → *Interview* → *Decision*.
- **Named Reviewer:** Highlights who is reviewing the profile (*Sarah from Tech Recruiting*).
- **Clear Timeline:** Sets exact expectations (*Expected update by Fri, Nov 20*).
- **Delay Safety Net:** Assures candidates they will never be ghosted.
- **Interactive Demo Bar:** Click the buttons at the top to simulate different hiring stages in real-time.
